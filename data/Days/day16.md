## 14/07/2026 [ Day 16: Users and Groups, the Windows Way ]

Running the Windows Server inside VMware today, managing local users through the GUI:

**Device Manager / Computer Management → Local Users and Groups → Groups → select a group → Add → type the username → OK**

This is the point-and-click equivalent of Linux's `adduser`/`usermod` from Day 3 -  different outfit, same basic job: deciding exactly who belongs to which group, and therefore what they're allowed to do on the system.
