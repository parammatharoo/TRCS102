# TRCS102

GNDEC 4-week institutional summer training.

## Training Details

- Organisation: Sensation Software Solution
- Course: Cyber Security
- Project: Web Crawler 
- Date of joining: 22/06/2026
- Completion date: 31/07/2026
- Counted as: 4-week institutional summer training

## Course Covered: Cyber Security

The training followed this syllabus:

1. Cybersecurity fundamentals and OS basics: CIA triad, common attacks (phishing, DoS, APT, malware), NIST and ISO 27001, Linux and Windows basics
2. Networking and security: OSI and TCP/IP, firewalls, IDS/IPS, symmetric and asymmetric cryptography, wireless security
3. Vulnerability assessment and penetration testing: CVE, CVSS, Nessus, OpenVAS, Nmap, Metasploit, Burp Suite
4. Incident response, malware analysis and digital forensics
5. Mobile, IoT and cloud security
6. Threat hunting and defensive security, OS and network hardening
